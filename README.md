# Zero POS System - نظام نقاط البيع

## 🚀 التشغيل السريع

### 1. فك الضغط
فك ضغط الملف في أي مجلد على جهازك

### 2. التشغيل
افتح ملف `index.html` في أي متصفح حديث:
- **Chrome** (موصى به)
- **Edge**
- **Firefox**
- **Safari**

### 3. أول استخدام
1. اذهب إلى `register.html` أو اضغط "تسجيل شركة جديدة"
2. أدخل بيانات شركتك + بيانات المدير
3. سجل الدخول بـ `admin@zero.com` وكلمة المرور `123456`

## 📱 التثبيت على الأجهزة

### Android (Chrome)
1. افتح الموقع في Chrome
2. اضغط القائمة (ثلاث نقاط) → "Add to Home screen"
3. سيتم تثبيته كـ app

### iPhone/iPad (Safari)
1. افتح الموقع في Safari
2. اضغط زر المشاركة → "Add to Home Screen"
3. سيتم تثبيته كـ app

### Windows (Chrome/Edge)
1. افتح الموقع
2. اضغط أيقونة التثبيت في شريط العنوان
3. أو من القائمة: "Install Zero POS"

## ✅ المميزات

| الميزة | الوصف |
|--------|-------|
| 📱 PWA | يعمل كتطبيق native على أي جهاز |

| 💾 Local Storage | البيانات محفوظة محلياً |
